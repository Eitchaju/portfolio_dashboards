# Publicação no GitHub

1. Revise o currículo público em `curriculo/` e adicione seu endereço GitHub.
2. Abra o projeto `portfolio.pbip` no Power BI Desktop e exporte capturas das cinco páginas para `imagens/`.
3. Verifique se os caminhos das fontes de dados CSV são portáveis e não incluem informações privadas.
4. No GitHub, crie um repositório público `customer-experience-analytics-powerbi` sem README inicial.
5. No GitHub Desktop, escolha File > Add local repository; se necessário, File > New repository apontando para esta pasta e então Publish repository.
6. Verifique README, arquivos PBIP, dados sintéticos e currículo PDF no GitHub.

O projeto é baseado em dados sintéticos. A publicação pública deve ocorrer somente após revisão pessoal.
